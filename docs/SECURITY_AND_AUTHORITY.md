# Security and Authority

The public Map of Reality remains non-executing: it has no shell endpoint, repository mutation endpoint, payment action, physical-machine control, or destructive API.

It now accepts one narrow write class: **sanitized physical evidence ingestion**. That endpoint does not accept a static shared credential. It requires a valid GitHub Actions OIDC token cryptographically signed by GitHub and constrained to the exact `Atlas-Ascend/Eden-2.0` main-branch physical-census workflow.

Unknown physical-census fields are dropped by an allowlist before public storage. Raw detailed evidence remains in private Eden-2.0 workflow proof.
