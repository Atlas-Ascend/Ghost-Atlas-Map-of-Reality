# Rainbow Council Protocol

Every case runs:

CASE -> PERSPECTIVE FAN-OUT -> INDEPENDENT READINGS -> CROSS-EXAMINATION -> CONVERGENCE MAP -> EVIDENCE/VALUES SPLIT -> MINORITY REPORT -> RAINBOW SYNTHESIS -> JANUS AUTHORIZATION.

Required outputs:
- agreement map
- disagreement map
- unresolved unknowns
- empirical claims
- normative claims
- symbolic claims
- historical claims
- speculative claims
- potential harms
- minority position
- source provenance
- confidence
